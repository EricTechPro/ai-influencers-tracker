| `ait-opportunity` | Velocity, indie score, verdict bands, the 0–100 score | 7 |
| `ait-analyze` | Topic matching, comment classification, step extraction | 8 |
| `ait-dashboard` | Start the dev server on 3002, open the browser | 9 |
| `ait-research-yt` | Per-video transcript extraction. Fork of `si-research-yt` | 14 |

One skill per directory, each with a `SKILL.md`.

`.claude/skills` is a symlink to this directory, so both harnesses read one source.
